# 1000 Coisas — Site estático

Este repositório inclui um site estático de demonstração para a loja "1000 Coisas" com identidade visual moderna (preto, amarelo, vermelho), design responsivo e animações suaves.

Como visualizar localmente:

1. Abra o arquivo `index.html` no seu navegador preferido.
2. Ou use um servidor estático (recomendado):

```bash
# exemplo com Python 3
python3 -m http.server 8000
# depois abra http://localhost:8000
```

Arquivos principais:
- `index.html` — estrutura do site
- `styles.css` — estilos e tema
- `script.js` — interações e animações
- `logo.svg` — logotipo simples

Observações:
- A paleta evita tons de azul conforme solicitado.
- O site foi projetado para ser leve e responsivo; imagens podem ser substituídas por fotos de produto reais.
